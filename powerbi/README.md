**2. Introduction to DAX in Power BI**

Completed: September 29, 2026

[Intro to DAX in Power BI Certification](https://github.com/meganz-1234/mis561-portfolio/blob/main/powerbi/Introduction%20to%20DAX%20in%20Power%20BI.pdf) * [Tableau Workbook Link](https://public.tableau.com/views/PowerBITrainingCertifications_17904654785640/PowerBIStory?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link) 

In my Flex 4 account profitability analysis assignment, I calculated discounted price for each order by subtracting the discount amount from the list price. In Power BI, I would create discounted price as a calculated column because it is a fixed value for each individual order rather than a calculation that needs to change based on report filters. This would keep the discounted price available at the row level while allowing other calculations and visualizations to use it. For Marcus, having this calculation in the data model would mean he could use the discounted price in different account or service-tier analyses without having to manually recreate the column each time.
